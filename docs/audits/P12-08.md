# P12-08 Readability and accessibility baseline

## Authorization and boundary

The owner authorized local P12-08 implementation on 2026-08-08. Commit, remote
publication, pull-request creation, merge, deployment, P12-08A, and later tasks
remain separately controlled and are not authorized by this local result.

The implementation is limited to shared readability, contrast, target-size,
focus, landmark, heading, unavailable-navigation, composition-segment, and
dynamic-rerender behavior. It does not change statistics, generated data,
schemas, workflows, catalogs, product availability, public entry or data paths,
classifier behavior, loading architecture, or protected event 434455 bytes.

## Implemented result

- Raised the shared production floor to 16-pixel body copy, 14-pixel table and
  key labels, 13-pixel secondary copy, and 12-pixel language controls. Compact
  language controls and other non-chart interactions retain at least 24 by 24
  CSS pixels.
- Kept that target floor as the hit area rather than the visible glyph size:
  tooltip `i` circles render at 16 pixels and subtype `+` / `-` circles at 18
  pixels, with a verified gap before the first mana symbol.
- Reserved a right-side accessory rail for numeric headers. Header text and
  column values now share an exact right edge while help icons and active sort
  arrows form one compact group beginning 4 pixels to its right without
  changing label width.
- Darkened the header's central orange-brown stop and introduced separate focus
  colors for light and dark surfaces. Muted, unavailable, matchup `N/A`, Top 8
  metadata, tip, and steady-state colors now satisfy their applicable contrast
  contracts without relying on color alone.
- Changed the dynamic `#view` host from an unnamed section to a neutral live
  container. Source notes are labelled asides, Top 8 has a view heading, and the
  Tabletop event summary is a named region.
- Unavailable format and product controls remain focusable, reference a shared
  localized explanation with `aria-describedby`, preserve focus, do not change
  the URL, and continue to publish a visible status message when activated.
- Added a shared composition-segment renderer. Each mapped identity is an
  independent button with a name, percentage, and expanded state; residual
  segments are labelled focusable images with no interactive descendants.
- Preserved proportional segment widths. Segments narrower than 24 pixels are
  the documented essential-visualization exception because the complete table
  supplies an equivalent named deck control.
- Dynamic rerenders restore focus to the equivalent initiating control. Closing
  MTGO statistics, Top 8, or Tabletop inline detail returns focus to its source
  deck control. Programmatic smooth scrolling also respects reduced motion.
- P12-08A remains separate: this task does not convert existing one-dimensional
  mobile tables and lists into cards.
