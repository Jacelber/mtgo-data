# P11-02 Ruff baseline

## Purpose

Introduce a small, reviewable Python linting baseline for maintained package
code without changing product behavior or converting Phase 11 into a broad
legacy cleanup.

## Scope

Ruff 0.15.22 is pinned in `requirements-dev.txt`, configured for Python 3.12,
and run in CI as `python -B -m ruff check src`. The baseline selects the F
rule family only. It fixes two unused package imports and documents four
unreachable legacy self-test references with narrow inline F821 exceptions.

The task deliberately excludes root compatibility scripts, tests, E-style
rules, import sorting, and formatting. The initial all-repository scan found
189 findings and 124 files that would be reformatted; that broader work is not
mechanical enough to include without separate authorization.

## Local validation

The task-local Python 3.12 environment installed the repository's pinned
development dependencies, then installed the local package for the existing
package-based tests. The pyproject-declared setuptools build tool was installed
only in that task-local environment; no system installation occurred.

- `python -B -m ruff check src --no-cache`: passed.
- Focused Ruff, CI-contract, Melee assembler, MTGO statistics, and package
  tests: 39 passed in 18.34 seconds.
- Repository validation passed: 179 Python, 1,635 JSON, 22 YAML, 30
  references, and 1,988 hygiene paths.
- Rule validation passed. Public Schema validation passed for 69 documents.
- Protected `434455` and Pages tests: 11 passed in 1.29 seconds.
- Full pytest: 667 passed in 412.80 seconds on Python 3.12.7.

Changed-path review must confirm that no `data/`, `data_raw/`, `stats/`,
`reports/`, `assets/`, `index.html`, or `melee/` production path changed. No
production workflow was dispatched and no remote write occurred.

## Stop point

Stop for owner acceptance after local validation. Commit, push, pull request,
merge, workflow dispatch, and P11-03 remain separately authorized.
