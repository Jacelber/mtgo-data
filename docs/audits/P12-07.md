## Implemented result

- Added a focused classic-script freshness renderer and product-specific fact
  mappers without adding a shared cross-product data metric. The separate asset
  preserves the established 25 KB maximum for each focused application script.
- MTGO statistics displays its selected period, data and classifier update
  times, deck counts, and high-score publication completeness.
- MTGO matchups displays its own available, expected, deferred, missing, and
  excluded coverage facts.
- MTGO Top 8 and Weekly Pickup display only their supplied week and available
  item counts. Top 8 does not expose DEC-083 provisional or sealed lifecycle
  state.
- Tabletop displays the selected event date, selected-event count, scoped deck
  count, submitted decklists, and unavailable decklists. A multi-event pending
  state does not invent aggregate deck facts.
- Missing values render as the localized value `Unknown` / `未知`, including
  partial completeness ratios, instead of being coerced to zero.
- At narrow widths the strip uses a two-column layout with period-like facts on
  a full row. This task intentionally does not remediate the surrounding legacy
  lists or product navigation reserved for P12-08A.
- The layout measures the rendered title and fact group instead of relying on a
  fixed breakpoint. When all content fits it remains on one row; otherwise the
  title takes the first row and the complete fact group starts at the same left
  edge on the following row.
