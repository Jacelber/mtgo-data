## Caller migration

Current README commands now use `mtgo-data-mtgo` and the relocated quality
tool. Live tests import classification, normalization, statistics, matchup,
Pickup, report, and public-contract behavior from `mtgmeta`. Wrapper-existence,
wrapper-parity, and obsolete-script integration assertions were removed while
their package behavior and byte-identical committed-output tests remain.

The Phase 3 contract fixture retains its original legacy-entry and hard-coded
inventory values as an explicitly historical snapshot. Its test no longer
requires retired files to exist in the current checkout.

The nine active root workflow and publication tools identified by P11-11 remain:

- `build_pages_artifact.py`;
- `ci_master_admission.py`;
- `ci_timing.py`;

- `validate_melee_candidate.py`;

- `validate_rules.py`; and
- `validate_schemas.py`.

Following the first pull-request clean-checkout run, `validate_repository.py`
gained one test-only subprocess rule. A test subprocess whose command directly
or indirectly references `mtgmeta` must declare `PYTHONPATH` in that child
process's environment. This prevents an already-installed local package from
masking a missing source-tree import path. The rule uses the existing AST
validation pass and does not add another pytest shard or execute another test
suite.
