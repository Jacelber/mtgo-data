# P11-05 — Monthly Dependabot proposal baseline

## Objective

Add review-only monthly proposals for the repository's pinned Python
dependencies and GitHub Actions references without changing production data,
statistics, front-end behavior, workflow permissions, or publication paths.

## Scope

- Add `.github/dependabot.yml` with the required root `pip` and
  `github-actions` ecosystems.
- Require exactly the two monthly entries through a repository test.
- Record that P11-04 was skipped after owner review of the measured CI cost.

## Deliberate boundaries

Dependabot proposals do not merge themselves. This task does not upgrade a
dependency, add a private package registry, configure auto-merge, modify a
GitHub Actions workflow, dispatch a workflow, or publish product data.

## Validation

Run the focused Dependabot configuration test, the complete pytest suite,
Ruff, mypy, repository validation, rule validation, Schema validation, and the
protected `434455` and Pages compatibility tests. Confirm that no generated
data, front-end source, public path, statistic, or frozen compatibility byte
changes.
