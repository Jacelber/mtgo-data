# P7-06 audit — Scoped hierarchical matchup statistics

Date: 2026-07-25

Status: local implementation completed; owner acceptance and remote
publication are pending.

## Purpose

Generate deterministic parent/subtype-aware matchup statistics for the
retained mixed-format Modern reference event `434455`. The output must support
future independent row and column expansion without changing the eligible
match sample or combining Melee with MTGO data.

## Frozen boundaries

P7-06:

- consumes the unchanged normalized event, classification overlay,
  opportunity ledger, and Modern taxonomy;
- keeps separate Day 1, Day 2, and all-Constructed-Swiss scopes;
- admits only complete reciprocal physical matches whose two ledger rows have
  `matchup_included: true`;
- stores a complete canonical leaf matrix and derives both parent axes by
  summing W-L-D counts;
- retains Unknown, every maintained event subtype, and explicit zero cells;
- preserves raw W-L-D counts and 95% Wilson intervals without inventing the
  unresolved OPEN-002 low-sample threshold.

P7-06 does not fetch data, modify retained inputs, change taxonomy, write MTGO
output, add `meta.json`, alter `schemas/manifest.json`, publish a catalog,
integrate a workflow, or change either front end. Those boundaries remain
P7-07 and Phase 8 work.
