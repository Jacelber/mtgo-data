## Purpose

Publish the owner-accepted Tabletop Major Events interface at
`/melee/index.html` while preserving the Phase 8 MTGO interface at
`/index.html`. Make product switching work across the two static entries
without merging their source data, loaders, caches, or statistics.

## Scope

P8-10 changes only the two production HTML entries, the shared Phase 8
front-end application and dictionary, front-end contract tests, and task
documentation. It does not change:

- generated MTGO or Melee data;
- statistical formulas or low-sample thresholds;
- classifiers, schemas, or workflows;
- public `stats/**` data paths;
- the retained Phase 4 rollback assets.

## Implementation

### Separate production entries

- `/index.html` remains the MTGO production entry.
- `/melee/index.html` is the Tabletop Major Events production entry.
- The Tabletop entry loads `tabletop-controller.js` for event data and retains
  `mtgo-controller.js` only for the explicitly labelled four-week MTGO
  comparison shown beside an event decklist.

Each entry declares its public-data base and the relative paths of both
production entries. The shared runtime continues to admit only `stats/**`
requests.

### Catalog-driven cross-entry routing

Products retain their existing catalog availability. Selecting a product on
the other production surface navigates to that entry and carries:

- `format`;
- `product`;
- `lang`.

The review prototypes remain non-navigating review surfaces. The Tabletop
entry defaults to Modern and Tabletop Major Events. If the selected format does
not offer the current product, the first available product in catalog order is
used. Consequently, choosing Standard from the Tabletop entry routes to the
Standard MTGO entry without disabling Standard itself.

### Tabletop bilingual contract

All Tabletop interface copy is now dictionary-backed. Chinese remains the
default, and English covers event/subview selection, mixed-event scopes,
overview metrics and tooltips, data-quality notices, matchup controls, and the
MTGO comparison disclaimer. Event names, player/deck names, IDs, and records
remain source data rather than translated interface copy.
