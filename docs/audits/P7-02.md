## Retention boundary

`mtgmeta.melee.retention` performs no network request. It accepts only a direct
timestamped snapshot under the approved event archive, validates raw manifest
Schema 2.0.0, requires exact resource and file coverage, verifies every
response's bytes and SHA-256, parses and normalizes the complete event, and
applies the existing fail-closed quality gate.

The repository's text policy excludes `data_raw/**` from line-ending
normalization. This preserves the source HTML's original CRLF bytes and keeps
the Git object, clean checkout, manifest digest, and parser input identical.

The normalized event is written atomically to:

`data/modern/melee/events/434455.json`

The immutable snapshot directory appears in every raw-artifact provenance path.
The source `fetched_at` is also the deterministic normalization epoch. A second
run reuses the existing byte-identical result. Different bytes at the canonical
path are rejected instead of overwritten. Failed partial collections remain
all-or-nothing temporary snapshots and cannot be mixed across source moments.
