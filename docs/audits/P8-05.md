## Purpose

Create the owner-approved backend product for the weekly MTGO Top 8 table
without changing the deployed front end, source collection, classification
rules, or statistical formulas.

## Product contract

The new `weekly_top8` capability enables:

- `python -B -m mtgmeta.mtgo --format <format> build-top8`;
- `stats/<format>/mtgo/top8/index.json`;
- `stats/<format>/mtgo/top8/YYYY-Www.json`;
- metadata discovery through `top8_catalog`;
- scheduled fail-closed generation for complete MTGO products.

`schemas/mtgo-top8-index.schema.json` and
`schemas/mtgo-top8-week.schema.json` validate the generated files. The
production manifest maps the Standard and Modern index and current week
documents, increasing its checked document count from 52 to 56.

## Placement and identity behavior

Every admitted event contributes exactly ordered ranks 1 through 8. An
available rank retains:

- exact player, main deck, and sideboard;
- stable parent and optional subtype IDs;
- a self-contained display label such as `Grixis Prowess`;
- a stable detail identity;
- the applicable parent/subtype four-week comparison reference and period end.

A missing rank remains an explicit placeholder with null identity, exact deck,
and comparison fields. Duplicate event IDs, duplicate Top 8 ranks, invalid
event metadata, or absence of any complete event week fail before publication.

## Historical-week boundary

The first catalog exposes only the latest complete week. The existing
`decks_4w.json` path is rolling and does not provide an immutable historical
construction base. Retaining an older Top 8 week while resolving its reference
to a newer average would be statistically misleading.

P8-07 must review the real payload and decide whether production UI acceptance
requires a separately versioned historical construction-base product. P8-05
does not invent that unapproved contract or precompute a new deviation field.

matchups, and before Pickup and metadata. Capability checks remain

Standard/Modern Top 8 index and ISO-week document paths; arbitrary new generated
paths remain blocked.
