# P11-08 — Playwright real-browser production baseline

P11-08 adds a pinned Playwright Chromium test layer without changing product
code, public data, public paths, or statistical behavior. The browser job runs
in parallel with the existing full CI jobs and remains under the workflow's
read-only permissions.

## Covered behavior

- MTGO Standard and Modern load through `/index.html`.
- Tabletop Modern loads through `/melee/index.html`.
- An unavailable Tabletop Standard request follows the catalog-defined fallback
  to MTGO Standard rather than presenting an invalid Tabletop product.
- Every scenario is checked in Chinese and English at 1440px desktop width and
  390px mobile width.
- Each loaded product must select the requested language, format, and product,
  render a visible content panel, clear loading and error states, and avoid
  uncaught page errors.
