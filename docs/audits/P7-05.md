# P7-05 audit — Per-event overview and deck statistics

Date: 2026-07-25

Status: local implementation complete; owner acceptance and remote publication
are pending.

## Purpose

Generate deterministic, source-separated overview, participant-deck, and
quality statistics for the retained mixed-format Modern reference event
`434455`. This task consumes the P7-02 normalized event, P7-03 classification
overlay, P7-04 opportunity ledger, and unchanged shared Modern taxonomy.

## Frozen boundaries

P7-05:

- writes only `overview.json`, `decks.json`, and `quality.json` under the
  event-specific Melee statistics directory;
- calculates Day 1, Day 2, and all-Constructed-Swiss scopes;
- keeps parent archetypes as the default aggregation and Unknown as an
  explicit denominator bucket;
- calculates maintained subtype children directly and proves additive
  conservation to their parent;
- preserves raw W-L-D samples and 95% Wilson intervals;
- retains the opportunity ledger's official point treatment for the
  disqualified participant while excluding the six affected matches from
  played win rate.

P7-05 does not fetch data, modify retained inputs, change the Modern taxonomy,
write MTGO output, generate a matchup matrix, generate `meta.json`, update the
public-output manifest, create a catalog or workflow, or change either front
end. Those boundaries remain P7-06 through Phase 8 work.
