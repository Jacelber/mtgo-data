## Narrow-screen regression and fix

At a 390 by 844 viewport, the deployed MTGO page kept page width at 375 CSS
pixels, while the Tabletop event selector forced the page to 464 pixels. The
data table itself already used the intended independent horizontal scroller;
the overflow came from `select#tabletop-event`.

The bounded fix wraps `.select-row` on narrow screens and allows its selector
to shrink to the available width. Local browser verification after the change
showed:

- Tabletop document width: 375 pixels;
- Tabletop viewport width: 375 pixels;
- event selector width: approximately 355 pixels;
- Tabletop table scroller: 323-pixel viewport over 1,250 pixels of content;
- MTGO document and viewport width: 375 pixels;
- desktop Tabletop event `434455`: loaded normally with 30 rendered rows.

No controller, data path, generated output, or statistical behavior changed.

## Phase-closeout blocker

The real Tabletop overview exposes 72 Unknown decklists among 362 submitted
Modern decklists. P7-03 had recorded these as explicit, non-blocking taxonomy
Unknowns, but P8-11 traced their current cause against the retained event and
unchanged Modern rules:

- 63 of the 72 Unknown decklists contain at least one Melee card name in
  `front face // back face` form;
- the shared rules use the canonical front-face name for cards such as
  `Ajani, Nacatl Pariah` and `Ral, Monsoon Mage`;
- the shared card-name normalizer currently resolves known aliases but does not
  normalize ordinary double-faced names to their front face;
- an in-memory diagnostic that changed only these names before rule evaluation
  reclassified 62 of the 72 Unknown decklists;
- examples resolve to existing rules such as Boros Energy and Ruby Storm;
- no retained event, classification overlay, or generated statistic was
  modified by the diagnostic.

This is a shared normalization/classification defect, not a display-only
issue. Correcting it requires regression tests for ordinary double-faced names,
deterministic regeneration of the Melee classification overlay and dependent
event outputs, and confirmation that MTGO classification remains unchanged.
It is therefore outside the authorized P8-11 patch and blocks declaring Phase
8 complete.

The remaining ten Unknown decklists require a separate taxonomy review after
normalization is corrected. They must not be guessed into archetypes as part
of the normalization fix.
