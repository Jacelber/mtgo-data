## Purpose

Connect the owner-accepted Phase 8 MTGO candidate to `/index.html` without
publishing the Tabletop Major Events entry. Preserve the former Phase 4 assets
as a rollback baseline, keep the public data paths stable, and restore the
Chinese/English behavior that existed on the previous production page.

## Scope

P8-09 changes only the static front-end entry, Phase 8 assets, regression
tests, and task documentation. It does not change:

- generated MTGO or Melee data;
- statistical formulas or low-sample thresholds;
- classifiers or schemas;
- production workflows;
- the future `/melee/index.html` entry.

## Implementation

### Production entry

`/index.html` now loads the accepted build-free Phase 8 shell and the MTGO-only
module boundary:

1. `runtime.js`;
2. `i18n.js`;
3. `matchup-model.js`;
4. `mtgo-controller.js`;
5. `app.js`.

The root entry does not load `tabletop-controller.js`. The catalog can continue
to describe backend-ready Tabletop data, while the MTGO production surface
keeps that product disabled until P8-10.

### Entry-aware public paths

Each entry declares its public-data base:

- root production entry: `data-stats-base="./"`;
- P8-07 and P8-08 review entries: `data-stats-base="../../../"`.

The runtime continues to admit only `stats/**` paths and rejects traversal.
This lets the same reviewed modules run from root and retained prototype URLs
without hard-coded production or prototype assumptions.

### Product capability gate

Catalog availability and surface availability are evaluated separately.
Standard and Modern enable only their published MTGO products on `/index.html`.
Tabletop Major Events remains visible but disabled with a development notice.
Changing format keeps the active product when the target format supports it;
otherwise the first available MTGO product is selected.

### Language behavior

The new Phase 8 dictionary is Chinese-first and re-renders the current product
when the language changes. It covers the production shell, MTGO share
statistics, matchup data, Top 8 tables, deck detail, completeness, and Weekly
Pickup. English Weekly Pickup comments use `comment_en` when present and fall
back to the retained Chinese comment.

The accepted English name for `MTGO占比统计` is
`MTGO High-Score & Top 8 Shares`.

### Rollback baseline

The previous Phase 4 files remain present and unchanged:

- `assets/css/site.css`;
- `assets/js/common.js`;
- `assets/js/matchup.js`;
- `assets/js/mtgo.js`.

Regression tests now distinguish the active Phase 8 production entry from
these retained rollback assets.
