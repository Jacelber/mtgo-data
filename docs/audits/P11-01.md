# P11-01 Python packaging and compatible console scripts

## Purpose

Establish the first Phase 11 engineering-baseline component: a standard Python
installation path and supported commands that do not require `PYTHONPATH`.

## Scope

This task adds `pyproject.toml`, package metadata, console-script declarations,
and the minimum package-local compatibility helpers required after installation.
It retains all root-level scripts and does not change production data,
statistics, front-end sources, public paths, workflows, configuration, or the
frozen `434455` compatibility boundary.

## Compatibility contract

- `mtgo-data-catalog` calls `mtgmeta.catalog:main`.
- `mtgo-data-mtgo` calls `mtgmeta.mtgo.__main__:main`.
- `mtgo-data-melee` calls `mtgmeta.melee.__main__:main`.
- Installed MTGO classification reports use the package-local report helper.
- Root `generate_classification_reports.py` keeps its historical default
  repository root and delegates to the same package helper.
- Root `public_contract.py` remains available to existing imports while package
  modules import `mtgmeta.public_contract`.

## Local validation

```powershell
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation --force-reinstall .
```

Python 3.12 virtual environments do not include the declared setuptools build
tool by default, so it was installed only into this task-local environment
before the no-build-isolation check. No system installation or dependency
manifest change was made.
