## Expandable catalog boundary

The following catalogs are intentionally excluded from the exact-byte set:

- `stats/modern/melee/index.json`;
- `stats/catalog.json`.

For the format catalog, the contract freezes its Melee Modern identity and the
complete selected event object whose `event_id` is `434455`. It does not freeze
`default_event_id` or other event entries.

For the global catalog, the contract freezes the selected Modern
`tabletop-major-events` product route:

```json
{
  "id": "tabletop-major-events",
  "available": true,
  "path": "stats/modern/melee/index.json"
}
```

It does not freeze `generated`, unrelated formats, other products, or future
catalog entries. The regression test adds unrelated in-memory entries and
changes volatile root fields to prove that legal expansion does not weaken the
selected projection.

## Migration rule

Contract version `1.0.0` declares:

- an exact-byte change requires a separately owner-approved version migration;
- catalog growth is allowed only when the selected projection is unchanged;
- regeneration of the legacy v2 snapshot is prohibited.

Tests must not update a digest merely to make a changed baseline pass. A
mismatch is evidence requiring investigation. If a deliberate migration is
approved, it must receive a new contract version, a decision record, reviewed
replacement evidence, and explicit owner acceptance before changing protected
bytes.
