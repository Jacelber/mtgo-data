## Implementation

`configs/pages_publication.json` admits:

- `index.html`;
- `fetched.txt`;
- `assets/`;
- `data/`;
- `data_raw/`;
- `melee/`;
- `reports/`; and
- `stats/`.

`build_pages_artifact.py` requires a new output directory outside the
repository. It rejects unsafe paths and symbolic links, copies bytes into the
fresh tree, verifies the copied SHA-256 values, generates empty `.nojekyll`,
enforces a 1-GiB ceiling, and writes a deterministic artifact-manifest digest
plus size report. It validates the event `434455` compatibility fixture, its
raw manifest, all 483 declared responses, eight exact normalized/generated
files, and two catalog projections before copying.

`.github/workflows/pages.yml` builds for relevant pull requests, every master
push, and manual review dispatch. Only a master push can configure, upload, and
deploy Pages. The build job has `contents: read` and no persisted checkout
credential. The deploy job has only `pages: write` and `id-token: write`, uses
the `github-pages` environment, and has no checkout or repository write path.
