# Modern Eldrazi Ramp subtype hotfix audit

Date: 2026-07-26

Branch: `codex/modern-eldrazi-ramp-subtype-hotfix`

Base commit: `1f205472938d8f9942102fdd95f48491456d1ac0`

Status: owner accepted the local implementation and authorized remote
publication and a post-merge MTGO production validation run.

## Production failure

The authorized MTGO production run
[`30184557061`](https://github.com/Jacelber/mtgo-data/actions/runs/30184557061)
successfully completed official-event and Videre collection, then stopped while
building Modern matchup statistics:

```text
classified archetype 'eldrazi-ramp' defines subtypes but selected none
```

The strict stop preserved the approved no-residual policy. No generated data
was published by the failed run.

## Reproduction and classification evidence

The production sequence was reproduced in an isolated workspace. It fetched
five new official Modern events and five corresponding Videre archives, then
reproduced the same matchup-generation failure.

Exactly one newly fetched deck triggered the condition. Participant identity
was not retained in the audit. Its relevant main-deck evidence was:

- four `Sowing Mycospawn`;
- four `Eldrazi Temple`;
- four `Ugin's Labyrinth`;
- four `Talisman of Resilience`;
- one `Underground Mortuary`;
- one `Bojuka Bog`;
- no `Talisman of Curiosity`.

The deck matched only `eldrazi-ramp-fallback`. The maintained Golgari rule
required `Overgrown Tomb`, so the equivalent black-green land
`Underground Mortuary` was not recognized.

## Resolution

The existing `eldrazi-ramp/golgari` taxonomy remains unchanged. No parent or
subtype was added.

Rule `eldrazi-ramp-golgari-underground-mortuary` adds the narrow missing
signature at priority `6445`, below the existing Golgari rule and above the
other Eldrazi Ramp color variants. Existing decks that match the original
Golgari rule retain their original selected rule.

The Modern taxonomy now contains 55 parents, 101 rules, and 54 subtypes. Its
rule SHA-256 is
`ccfc989d110245efe253b26267ca524896a2db46edca5f5bcdad73c595b38cdb`.

## Compatibility evidence

The frozen 5,792-deck Modern corpus retains exactly:

- 5,664 classified decks and 128 Unknown decks;
- 2,329 selected subtypes;
- 1,519 multiple matches;
- 132 same-parent multiple-subtype matches;
- zero conflicts and zero invalid decks;
- every frozen parent, subtype, transition, and representative selected rule.

The retained Pro Tour event `434455` also remains exactly:

- 362 records;
- 290 classified and 72 Unknown;
- zero conflicts and zero invalid decks;
- 2,910 opportunities and 1,394 win-rate matches;
- 29 observed parents and 55 leaves.

Its classification overlay and dependent opportunity, statistics, matchup, and
metadata documents were regenerated by their official commands. Their only
field changes are the Modern taxonomy rule count/hash and the resulting
downstream file hashes.
