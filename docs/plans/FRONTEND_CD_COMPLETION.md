## 已补齐的行为

1. **MTGO 对局刷新包含主流筛选依据。** 开启主流筛选时，暂存同区间 `range`、矩阵与完整度；三者区间一致、range 与矩阵分类摘要一致才允许应用。关闭筛选时仍不额外加载 range。此前能出现新矩阵配旧占比集合，现在三者一起更新。
2. **分类名称和视图数据一起刷新。** 刷新开始固定目标及上下文，暂存名称契约，再以新契约检查数据身份覆盖；Tabletop 多赛事也使用新名称中的身份顺序。点击应用时同步更新数据缓存、名称原始 JSON 缓存、赛制名称缓存和活动名称。仅改名也会提示更新；缺名称或加载失败不提交。过期刷新仍不能覆盖导航后的页面或名称。显式 Unknown 沿用既有表示，不伪造分类名称。
3. **单赛事矩阵接入共享严格校验。** 首次加载和暂存刷新都核对版本／编码、来源、事件身份、分类摘要、全部声明 scope 的身份域及完整行、格子计数、反向／镜像和实际对局守恒。旧密集版缺列拒绝，新稀疏版允许已知列的零格省略，但不允许整行丢失；同时拒绝互相矛盾的 W/L/D 与 literal record。共享同一验证逻辑给多赛事聚合。成功结果按 JSON 对象复用，单赛事切 scope／筛选不重验；新刷新对象重新验证。首次坏数据失效后可重新请求，后台坏刷新不破坏现有缓存。
4. **中文卡名资源按消费者需要加载。** 中英文矩阵均不依赖卡名 lookup；中文统计、Top 8 和 Tabletop 概况仅在详情需要卡名时加载。Landing 首屏展示卡牌与卡名，因此继续加载。可选资源失败时保留既有英文回退。
