# Broodscale 的异常备牌：按法术力基础保留 Gruul

最新 Owner 明确：新增混色应有正常法术力基础支持；Springleaf Drum 等通用产色神器、单张 The Mycosynth Gardens 不独立构成混色依据。按这一口径，原记录中的 2 张 Wailing Ghoul 不增加黑色，保留 `broodscale-combo/gruul`，不新增 Jund。该结论已经由共享颜色逻辑得到，没有建立牌表专用覆盖。

Warping Wail 只是对可能登记错误的推测，并非核实事实。原始卡名、数量继续保留；不替换为 Warping Wail，不建立卡名别名，也不全局排除 Wailing Ghoul：若正常黑色法术力基础支持它，则仍计入黑色。是否为护身符、误录或其他用途无需作为本次分类依据。

原始 Melee 输入 `cards` 数组直接记录 Wailing Ghoul，没有经过本轮别名替换。主牌可能提供黑色的来源是 Springleaf Drum、The Mycosynth Gardens，以及带运气指示物的 Gemstone Caverns；Cavern of Souls 还有生物类别限制。这些是理论产色途径，不能按已确认口径单独构成新增混色的依据。
