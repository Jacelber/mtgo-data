# 首轮分类器材料索引

本目录保留各问题提出时的完整牌表、诊断和业务边界讨论。单份 REVIEW 中的建议或待定状态不自动代表最后决定，也不替代当前规则。

- 最终分类变化：[IMPACT_REVIEW.md](IMPACT_REVIEW.md)。
- 实施经过及用途例外：[IMPLEMENTATION.md](IMPLEMENTATION.md)。其中的阶段数字按记录当时理解。
- 阶段同步与交付经过：[DELIVERY_PROGRESS.md](DELIVERY_PROGRESS.md)。
- 最新源码版本、固定验收包及远端整合情况：[源码交付准备](../SOURCE_DELIVERY_PREPARATION.md)。
- 整体开发位置：[DEVELOPMENT_PLAN_CURRENT.md](../DEVELOPMENT_PLAN_CURRENT.md)。

本轮使用明确规则、共享颜色依据与局部例外。原始来源不改写，历史基线不被新自动输出覆盖；不推进 Legacy 分类器或行为分析。
