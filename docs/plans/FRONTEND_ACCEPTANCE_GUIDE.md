## 打开固定预览

完整本地预览包：`/workspace/scratch/rounde/final/mtgo-review.zip`。

首轮反馈修正版：在旧包基础上应用 `/workspace/output/mtgo-review-update.zip`，无需重下整站。把包内 `apply-update.py` 与 `update-files` 放到旧 `preview.py` 同级，停止原服务后运行 `python apply-update.py`，再重新启动预览并刷新浏览器。该更新已校验与 `/workspace/scratch/acceptance-final/` 的新版固定候选一致。分享图标位置已经定稿，不重复请求确认；原包保留用于对照。

完整解压后，在该目录运行 `py preview.py`（Windows）或 `python3 preview.py`（macOS／Linux），会自动打开验收导航。只需要 Python 3，不需安装项目依赖。浏览器未自动打开时，使用终端打印的 Preview 地址。结束时 Ctrl+C 停止服务。

不要直接双击产品的 HTML：产品需要通过本地 HTTP 读取 JSON。云环境的 localhost 仅用于内部验证，不冒称是你可直接打开的公网地址；本轮没有部署公开预览或生产站点。

预览包内 `review.html` 为单独验收导航，提供全部实际入口；`site/` 为与完整候选绑定的产品文件。验收导航和启动脚本不进入生产部署包。

## 建议操作

| 路径 | 重点判断 |
| --- | --- |
| 占比统计：区间、排序、子类、牌表详情、代表牌表模式，再分享 | 状态和内容一致；新标签页恢复同一内容；标题、区间与详情表达清楚 |
| MTGO 矩阵：主流筛选、自选套牌、展开行列、分享与前进／返回 | 自选结果、主流集合和展开状态恢复正确；复制及失败回退提示易理解 |
| 矩阵键盘：Tab、方向键、Home／End、Esc | 能到达需要的格子、读到简短战绩提示；退出提示与筛选草稿顺畅；格子内 ± 沿用原义 |
| Landing 特选／八强：打开牌表、复制、重新打开 | 链接恢复同一周、同一条目及详情；Esc 关闭后能继续操作 |
| 实体赛：单场范围、多赛事选择、筛选、详情与分享 | 赛事集合和范围表达正确，与 MTGO 入口保持清楚区别 |
| 桌面／手机、中英文、更新和失败状态 | 新按钮和提示可见可用；加载、更新、失败、重试文案明确；截图中的状态效果可接受 |

受控更新、切换失败及重试的截图在导航底部；普通页面仍使用真实保留数据。无需你模拟损坏 JSON、核对哈希或测试统计公式，这些由 Codex 负责。

## 覆盖范围

验收导航分别列出 Standard、Modern、Pioneer、Pauper 四赛制的 Landing、统计、矩阵、八强，并提供中文与英文入口；实体赛只列已上线的 Modern、Pauper 概况和矩阵。没有新增 Legacy 或未上线的实体赛产品。

确认只覆盖实际展示并被接受的对象与语言，不把“看了一个页面”当作全部页面通过。你可以直接给出整体反馈，也可以注明暂未查看的部分，不需要逐条技术审批。未展示的内容不会自动获得上线资格。
