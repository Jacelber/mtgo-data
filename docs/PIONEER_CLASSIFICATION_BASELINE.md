# Pioneer 私有分类基线

2026-09-13 已完成首批分类及名称确认。Pioneer 仍为 `public: false`，
仅启用共享分类能力；这不是赛事公开接纳、周维护完成或 Phase 15 完成。

## 已确认划分

- 莲花变境 / Lotus Scapeshift：保留苏勒台、蓝绿子类。
- 蓝白控 / Azorius Control：保留普通、约力昂子类。
- 使用操纵比赛组件的绿色献力归入大绿献力。
- 秘笼与操纵比赛双轴归秘笼操纵比赛 / Fight Rigging Cage；目前输入为
  白绿构筑，不含尼索斯，不归绿色献力。
- 贴皮 / Auras 不设颜色子类。现有两份构筑法术力基础相同方向，
  不因单张黑色贴皮另建子类。

其他已确认身份及名称见 `my_archetypes/pioneer.yaml` 和
`configs/mtgo_archetype_names.yaml`。规则使用共享执行器，不使用赛事、
牌手、排名或人工标签作为匹配条件。

## 输入与结果范围

人工参考覆盖 2026-03-30 至 2026-09-06，共 153 场、2,291 个非空标签，
另有两个空白。每条已按赛事和实际排名对应到原始牌表；同日同人数赛事
结合前列实际构筑区分。工作簿及逐条私人反馈保存在私有审阅材料中，
不进入仓库或公开站点。原表不改写，已确认更正与原标签分别保留。

所有非空参考牌表均可分类，参考差异已获确认。该参考也用于调整规则，
因此一致性结果不是独立测试集的准确率估计。

同输入全量比较覆盖 155 场、4,960 份牌表，包括为参考补齐的一场私有
历史输入。最终边界修改只涉及 14 份献力归并、1 份秘笼操纵比赛和2份
贴皮身份调整，其余 4,943 份身份不变。结果为 4,900 份已分类、57 份
未识别、3 份混合构筑冲突；后两组均在非空人工参考之外，不能视为已
分类或已获逐条人工确认。

验证复用共享分类执行机制，核对本次全量变化、名称消费者、原始引用及
私有只读页。没有为规则内容变化运行全套机制测试，也没有发布产品。

## 后续工作

剩余分类已于同日完成：固定 4,960 份输入全部分类，无未识别或冲突。
其中 60 份原未识别／冲突完成归类；依据 Owner 明确的进攻生物自磨边界，
另将一份带 4 张 Willow Geist 的历史发掘归入自磨，其余 4,899 份身份不变。
人工参考的 2,291 份身份不变。新类别名称已获确认并保存。

四色传奇采用英雄广场和传奇生物群识别，不使用杰斯／瓦尔基单卡命名；
排除传奇圣物主轴，与五色传奇互斥。罕见的物尽其用回手直接归蓝黑回手。
自磨 / Self-mill 以自磨引擎及 Souls of the Lost、Willow Geist 或 Moonshadow
等进攻生物为边界，与发掘分开统计。

既有规则优先修改必需牌条件。蓝白控的无泰菲力版本、红黑鬼怪的不同
部族核心、红白烧的不同直伤组合仍需替代分支；自磨三种不同进攻生物
用三条规则表达“任一”条件，不复制分类执行机制。
