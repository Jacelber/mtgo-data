# Claude repository adapter

`AGENTS.md` is the mandatory entry point and complete stable agent guide for
this repository. Read it first, then read every authoritative document it lists
in order before analyzing, planning, editing, or generating code.

This file adds no project state, product rules, statistical rules, or standing
authorization. In particular:

- use `docs/STATUS.yaml` for the current phase, task, blockers, authorization,
  protected scope, and stop point;
- use `docs/DEVELOPMENT_WORKFLOW.md` for workspace isolation, approvals,
  publication, and stop conditions;
- treat `PROJECT_NOTES.md` and `docs/history/` as non-authoritative history;
- never infer authorization from a roadmap entry, old status snapshot, legacy
  code, or this adapter.

Follow `AGENTS.md` when guiding the non-programmer owner: work one task at a
time, explain the result plainly, give exact verification instructions when
owner action is needed, and stop at each authorization boundary.
