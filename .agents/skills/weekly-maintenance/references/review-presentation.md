# 审阅介质

分类、规则修订和内容选稿均沿用 `tools/weekly_review_web.html` 的既有审阅方式。
`weekly_maintenance.py` 的 classification 与 inspect 共用该页面骨架及
`tools/weekly_maintenance_review.js`；扩展所需事实时保留原有可读性和定位操作。

- 分类：MTGO 按赛事分列、排名分行，固定表头，突出搜索结果、Unknown 和机器提示。
  Melee 独立列表可搜索、筛选，每份可用牌表均可直接打开；不可用资料单列。
  规则修订提供清楚的原分类、拟议分类和理由，并链接每份受影响的完整牌表。
- 内容：环境占比及代表牌用对齐表格；待定项与沿用项明确区分。Feature 候选逐条展示
  可读理由，增减明细按需展开；全部八强另有可搜索目录，保持原顺序与 F 编号。
- 牌表：点击一次进入详情，主牌／备牌分栏并显示数量合计，中文为主、英文辅助定位；
  窄屏改为上下排列。保留固定链接、可复制引用及关闭后原列表位置。
  完整牌表随快照提供，不需要用户再追问，也不铺成长篇正文干扰总览。

修复先复用固定材料，只更换呈现。原快照、事实、来源、编号和确认记录保留；
修改维护中的生成器并为当前批次生成新版本，避免依赖本周临时 HTML 补丁。
格式修复不代表内容已验收，也不重启已结束的分类判断。

已有快照仅修复格式时执行 `python tools/weekly_maintenance.py render --root ROOT
--kind content --input INVENTORY_JSON --localization CATALOG --output NEW_DIR`；
分类材料改用 `--kind classification --input MATERIALS_JSON`。该入口保留原事实，
不重新分类、筛选或采集；固定引用不变，新的页面另存。

交给 Owner 前操作实际页面：从总览找到指定条目，搜索一个中文类别和编号，
打开完整主备牌、关闭返回，并检查直接链接、无结果状态、长名单和窄屏。
同时核对原材料记录数、牌表数量及固定引用保持一致。页面可访问或 JSON 齐全
不能单独证明可审核；可读性不足时先恢复介质，再提交受影响的体验维度。
