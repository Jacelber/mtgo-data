# MTGO 公众号周报配图

使用 [scripts/generate_images.py](scripts/generate_images.py)，沿用 Owner 已确认的标准与摩登样式。读取当前项目 AGENTS.md；统计定义见 docs/STATISTICS_SPEC.md，公众号特定口径见下文。

## 开始与输入

确认本次赛制和目标完整自然周（周一至周日）。周一制作的“本周周报”指刚结束的一周，在回复中给出实际日期。未指定赛制时，从 configs/formats.yaml 选取已公开、可执行且具备 weekly_top8 能力的 MTGO 赛制；仅选择指定范围，不因配图接入新赛制。

只读核对目标周应有赛事、现有留存赛事以及分类版本。通常使用当前已确认分类；用户明确要求按现有分类试制时保留该版本。候选规则只在本次明确选择或已确认时采用。用同一套规则重算本周与之前4周；不将不同分类版本的既有百分比拼接。

正式稿核实输入覆盖及分类状态；试制稿忠实保留已知缺口和未分类，不替换成上周，也不自动补采或修改规则。应有赛事数需来自已查明范围，不用留存文件数冒充完整性证明。缺少完整参考周时查明缺口或真实无赛事状态，不能填成零。

## 统计与展示

- 所有套牌按子类身份独立统计、使用已批准中文名；没有维护子类的套牌使用自身身份。有子类的父类不重复汇总。未分类显示“未分类”，缺失八强牌表保留名次并显示“牌表缺失”。
- 本周、上周分别统计。“近4周平均”保持这个表头，取本周之前4个完整自然周，合并原始数量计算占比，不含本周。高分和八强各用该时段自己的总数作分母，包含有效未分类。
- 本周高分占比 ≥ 2% **或**近4周高分占比 ≥ 2% 即单列，其余合并“其他”。六列使用同一单列集合；先按未舍入比例筛选，再显示1位小数。按本周高分占比降序，并列依次按近4周占比降序、稳定身份排序；“其他”最后。
- 八强表按赛事时间、ID排序，每场一列、每列1—8最终名次。表头第一行“X月X日＋特殊赛事简称”，第二行“（N人）”。普通 Challenge 只写日期；Showcase Challenge → SC，RC Super Qualifier → SQ，RC Qualifier → RCQ，Showcase Qualifier → SCQ。其他类型沿用项目现有紧凑名称；尚无明确简称时展示可识别的类型名，不编造。
- 每个赛制只生成两张PNG。八强表每组最多7场，超出后在**同一张图**向下分组，每组重复排名、表头。白底、灰表头、黑边框，完整中文名称；长名称缩字号。图片**只保留表格**，不加标题、水印、赛事ID、样本数、试制标记或统计说明。

## 执行与核对

使用项目 Python 3.12、PyYAML 和 Pillow；需要图片运行时时查询桌面 `load_workspace_dependencies`，不要把本机运行时绝对路径写进 skill。脚本会复用 `--repo` 或 `--code-root` 下已有 `.venv/Lib/site-packages`；使用其他运行时则提供对应环境的包路径。参数以脚本 `--help` 为准。

在仓库根目录按赛制调用，使用新的 Pages 排除目录。示例：

```powershell
python .agents/skills/mtgo-weekly-article-images/scripts/generate_images.py --repo . --format modern --week 2026-W42 --out outputs/article-images/2026-W42/modern-v1 --expected-current-events 13
```

已授权试制时添加 `--draft-note "实际数据缺口或分类状态"`。说明仅写入核对文件与回复，不写进图片。复现已确认成果时以原 `inputs` 快照作为 `--repo`，以实际项目源码根目录作为 `--code-root`，保持原版不变。

输出为 `<format>-<week>-top8.png`、`<format>-<week>-shares.png`，附带 `table-data.json` 及规则、语义配置、名称、5周赛事的精确输入快照。这些辅助文件只用于本地核对，不混入线上数据。应有赛事数和备注不能自动证明用户接受分类或准许发布。

提交图片前核对实际赛事与1—8名、叶子身份、阈值、排序、六列原始计数及“其他”补集；占比机制已有有效证明可复用。解码并查看真实PNG，检查中文、最长名称、特殊赛事日期及多组边界。保留验证通过的同一版，复用已确认排版，不每周重问样式。

在回复中直接展示两张图片或每赛制对应的图片，简述周区间和实际未决状态，给出下一步；用户未要求时不自动发送公众号、采集、启动周维护或发布。生成器不会把配图完成当作周维护完成。
