P12-15 favicon assets use three independently composed, owner-accepted cat
illustrations. They share the warm-brown page header midpoint (`#8f4827`), the
same ivory tabby outline, olive eyes, and pink nose, while preserving only the
detail each rendered size can display clearly.

- `apple-touch-icon.png` (180 by 180): owner-selected detailed tabby portrait;
- `favicon-32.png` (32 by 32): compact portrait retaining the tabby forehead
  markings;
- `favicon-16.png` (16 by 16): compact portrait retaining the silhouette,
  eyes, nose, and three forehead markings.
